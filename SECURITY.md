# Security policy

Report suspected vulnerabilities through the repository's
[Security tab](https://github.com/ultimatechris/bpmn-di-gen/security). Use
**Report a vulnerability** to send the report privately.

Include the affected version, the potential impact, and a minimal example that
reproduces the issue. Use sample BPMN files with any credentials and private
process data removed. Use GitHub Issues for ordinary bugs and feature requests.
